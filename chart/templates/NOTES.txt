** Please be patient while the chart is being deployed **

OpenLDAP can be accessed on the following DNS name from within your cluster:

  {{ include "common.names.fullname" . }}.{{ include "common.names.namespace" . }}.svc.{{ .Values.clusterDomain }} (port {{ .Values.service.ports.ldap }}{{ if .Values.tls.enabled }}, LDAPS port {{ .Values.service.ports.ldaps }}{{ end }})

To get the admin password run:

  export LDAP_ADMIN_PASSWORD=$(kubectl get secret --namespace {{ include "common.names.namespace" . }} {{ include "openldap.secretName" . }} -o jsonpath="{.data.{{ .Values.auth.secretKeys.adminPasswordKey }}}" | base64 -d)

To query the directory from your computer run:

  kubectl port-forward --namespace {{ include "common.names.namespace" . }} svc/{{ include "common.names.fullname" . }} 1389:{{ .Values.service.ports.ldap }} &
  ldapsearch -x -H ldap://127.0.0.1:1389 -b "{{ .Values.ldap.root }}" -D "cn={{ .Values.auth.adminUsername }},{{ .Values.ldap.root }}" -w "$LDAP_ADMIN_PASSWORD"

{{- if not .Values.ldap.skipDefaultTree }}

User passwords ({{ join ", " .Values.auth.users }}) are stored comma-separated in the "{{ .Values.auth.secretKeys.userPasswordsKey }}" key of the same secret.
{{- end }}

NOTE: credentials, the default tree, custom LDIF and schema files are only applied on the first boot.
Changing them afterwards does not update an existing directory.
{{- end }}
